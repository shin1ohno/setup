先週、倉庫の古いラベルプリンタが壊れた。印字ヘッドの交換は手順書どおりに進めたが、固着したネジを外すのに骨が折れた。作業台の引き出しにある道具では足りず、隣の部署から精密ドライバーを借りた。交換後もラベルが少しずれるので、設定画面で印字位置を既定値に戻した。ヘッドを替えた直後にずれ始めたので、原因は取り付け角度の誤差だと考えられる。来週、メーカーの点検で確かめてもらう。
