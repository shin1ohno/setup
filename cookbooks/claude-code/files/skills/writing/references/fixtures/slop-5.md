この設定変更は、障害対応の手順に地味に効く。古い手順のまま運用すると、監視が静かに沈黙したまま実害が出るという事故が起きやすい。落とし穴は、既定のタイムアウトが本番の負荷とは別物になっている点だ。そこで手順書では監視の仕組みまで踏み込み、ログとアラート履歴を突き合わせる作業を入口に据えた。この確認が運用全体の土台になる。
