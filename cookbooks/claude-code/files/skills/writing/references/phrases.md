# phrases.md — 語彙レベルの AI 臭辞書

語彙・フレーズ単位の禁止トークン集。`structures.md`（文章構造）と直交する。どの語も 1〜2 回なら自然だが、1 文書に頻出すると AI 臭になる。原則は「撒くな」。全部消す必要はない。孤立した 1 語は直さず、同じ文書に複数の tell が固まっているときだけ直す（クラスタ規則。編集者 persona の Cluster rule と同じ）。

> ヘッジ・suggest 直訳・確認伺い・後送りの基本禁止セットは `~/.agents/AGENTS.md` の `## Japanese Output Discipline 禁止表現` が正典。本ファイルは重複させず、文章作成固有の AI 臭（偏愛語・翻訳調・比喩動詞・機械アーティファクト等）を追加で扱う。

各エントリは `NG表現 | 問題（なぜAI臭か）| 推奨（置換）| 例外（allows）` の 4 列。`検出:` 行は grep のシード（`rg` で機械検出する）。シードは候補を拾うだけで、当たった語を直すかどうかは例外列とクラスタ規則で決める。

言い換えの共通条件（全節に適用）:

- **含みを残す**。比喩や副詞が運んでいた気持ち・評価の向き（「地味に」の目立たないが確かな感じ、「〜てしまった」の後悔、「ようやく」の待ちくたびれた感じ）は、語を替えても別のふだんの言葉で残す。
- **足さない**。言い換えのついでに、原文にない原因・条件・動作主・数値・固有名詞を入れない。ぼかした語を、より狭い具体的事実に置き換えない。情報が足りなければ「書き手に確かめたい点」に回す。
- **硬くしない**。比喩を消して硬い漢語（「整合性が失われる」「発生する」）に置き換えるのは、原文や前後からその意味だと分かるときだけ。

## 1. 偏愛語・過剰強調

| NG表現 | 問題 | 推奨 | 例外 |

| 画期的な / 革新的な | 評価を装うだけで中身ゼロ | 何がどう新しいか具体化 | 引用・他者発言内なら可 |

## 6. 接続詞連打（閾値ルール）

接続詞は論理を語順で示せば多くは不要。**1 文書に同種が 3 回以上で過剰**。半分削り、文の順序で論理を伝える。

検出: `また、|さらに、|加えて、|したがって、|一方で、|このように、|とりわけ、|しかしながら、`（合計頻度を数える）

## 9. 比喩動詞（病理① の語彙）

モノや抽象概念を主語にして、体の動きを表す動詞で語る癖。構造面（主語の立て方）は structures.md 1 で扱い、本節は語彙を扱う。直すときは冒頭の共通条件（含みを残す・足さない・硬くしない）を必ず守る。

| NG表現 | 問題 | 推奨 | 例外 |
|---|---|---|---|
| 効く / 効いてくる（「地味に効きます」） | 何がどう役立つのかを比喩で省く | 「目立たないが役に立つ」「少しずつ助けになる」。「地味に」の含みは残す | 薬・治療・味付けなど文字どおりの「効く」は可 |
| 〜側に倒す / 〜に倒す | 判断の向きを比喩で言う | 「〜を優先する」「〜の扱いにそろえる」「外す」 | スイッチ・レバー・物を物理的に倒す場合は可 |
| 時間を溶かす | 浪費を比喩で言う | 「思った以上に時間がかかってしまった」。後悔の含みは残す | — |
| 1 つずつ潰す | 対処を比喩で言う | 「1 つずつ直す」「解消する」 | 物理的に潰す場合は可 |
| 〜まで踏み込む | 調査・議論の深さを比喩で言う | 「〜まで詳しく調べる」「〜まで扱う」 | 文字どおり足を踏み入れる場合は可 |
| 引き返す（作業・状態について） | 手戻りを比喩で言う | 「元の状態に戻す」「やり直す」 | 道を戻る場合は可 |
| 〜が添える（仕組み・経路が主語） | 受け渡しを比喩で言う | 「渡す」「付ける」 | 人が花・言葉を添える慣用は可 |
| 〜に収斂する | 落ち着き先を硬い比喩で言う | 「〜に落ち着いた」「〜に決まった」 | 数学・物理の収束の意味で定義して使う場合は可 |
| 沈黙する（システム・処理が主語） | 無反応を擬人化する | 「応答しない」「何も出さずに終わる」。原因を勝手に狭めない | 人が黙る場合は可 |
| 黙って〜される（「黙って捨てられる」） | 通知のなさを擬人化する | 「気づかないうちに捨てられる」「知らないうちに無視される」 | 仕組みとしてエラーや通知が出ないと原文から明らかなときだけ「エラーを出さずに」「通知なく」 |
| （データ・システム・設計が）壊れる | 不具合を物の破損で言う | 「おかしくなる」「使えなくなる」のように指す範囲が同じくらいの語に替える。言い切りの強さは弱めない | 時計・機械・身体など文字どおりの物理的な「壊れる」は可。整合性の話だと原文から明らかなときだけ「整合性が失われる」 |

定着した慣用句（骨が折れる、手を焼く、目から鱗が落ちる、首を長くして待つ 等）は比喩動詞として扱わず、そのまま残す。判断に迷う語は、生成 AI 以前の書籍や記事でも普通に使われていた言い回しかどうかを基準にし、使われていたなら直さない。業務文書でも、読み手が誤解しない限り残す。

検出: `効(く|き|い|か)|に倒(す|し|そ)|溶か(す|し)|潰(す|し)|踏み込(む|ん|み)|引き返(す|し)|が添え(る|て|ら)|収斂|沈黙(する|し)|黙って|(データ|システム|設計|整合性|状態|ファイル)が(静かに)?壊れ`

| NG表現 | 問題 | 推奨 | 例外 |

| 結末 / 宿命 / 運命 | 日常の出来事に物語の重みを付ける | 「結果」「そうなりやすい」 | 物語・作品の紹介で文字どおり使う場合は可 |
| 虚飾 / 虚像 / 美学 | 中身のない対立軸を立てる | 何を飾りと見ているのかを具体名詞で書く | 美術・思想の文脈で定義して使う場合は可 |

## 11. 質感・認知を装う語

現場を知っている風を装うが、何をどこまで知っているのかが書かれていない語。

| NG表現 | 問題 | 推奨 | 例外 |
|---|---|---|---|
| 手触り / 肌感 / 肌感覚 / 体温 / 温度感 / 熱量 / 血の通った / 泥臭い | 感覚語で中身を省く | 原文に書かれている事実に言い換える。書かれていなければ事実を創作せず、ぼかしの度合いが同じ平易な語に替えるだけにする | 体温・熱量の物理的・医療的な用法は可 |
| 解像度を上げる / 解像度が高い / 腹落ち / メンタルモデル | 理解したと装う | 何をどこまで調べた・分かったのかを、原文にある範囲で書く | 画像・ディスプレイの解像度、認知科学の術語として定義済みのメンタルモデルは可 |

## 12. 急増語

AI が普及した後の技術文書で目立って増えた比喩・評価の名詞（Qiita 記事の大規模調査による分類）。どれも 1 語なら普通の日本語なので、冒頭の原則「撒くな」とクラスタ規則をここにも適用する。同じ文書で複数語が固まっているときだけ直す。12-1・12-3・12-4 は**比喩用法に限る**。文字どおりの用法（交通事故、建物の入口、作業の道具）は対象外。

### 12-1. 障害・失敗の比喩（比喩用法に限る）

| NG表現 | 問題 | 推奨 | 例外 |
|---|---|---|---|
| 事故（「〜という事故」） | 設定ミス・不具合を大事故のように言う | 「思わぬ失敗」「トラブル」 | 交通事故・労災など文字どおりの事故は可 |
| 混ざる（設定・データが） | 混入を比喩で言う | 「入り込む」「紛れ込む」 | 液体・材料が混ざる場合は可 |
