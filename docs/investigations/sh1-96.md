# SH1-96: 補完後に残る suffix

zsh の編集行は正しく補完されていますが、旧 profile が再読み込みした
fzf-tab が autosuggestions の wrapper を外し、`POSTDISPLAY` に旧候補を残します。
この再現は通常 PTY と Herdr 0.9.1 の両方で発生しました。

## 最小再現と観測

私有 HOME / ZDOTDIR に `ManagedProjects/setup/` を作り、履歴へ
`cd ManagedProjects/setup` を追加します。compinit、fzf-tab、zsh-defer を読み込み、
autosuggestions、fast-syntax-highlighting、旧 profile の fzf-tab 再読み込みを
この順で defer します。`cd ManagedProjects/s` と入力して Tab を押します。
コマンドを実行する Enter は送信しません。

| 状態 | BUFFER | CURSOR | POSTDISPLAY | 端末セル |
| --- | --- | --- | --- | --- |
| 補完前 | `cd ManagedProjects/s` | 20 | `etup` | `cd ManagedProjects/setup` |
| 旧 profile あり、補完後 | `cd ManagedProjects/setup/` | 25 | `etup` | `cd ManagedProjects/setup/etup` |
| 旧 profile なし、補完後 | `cd ManagedProjects/setup/` | 25 | 空 | `cd ManagedProjects/setup/` |

明示的な redisplay 後も同じ値です。旧設定では PTY 出力に
`setup\x1b[1m/\x1b[0metup\x1b[K\x08\x08\x08\x08` が含まれます。
`etup` は消去漏れのセルではなく、zsh が出力した候補表示です。
修正後は補完後・再描画後とも `POSTDISPLAY` が空です。
独立した tmux 端末への raw bytes 再生でも、同じセルの差を確認しました。

## 所有元と原因

- `cookbooks/fzf-tab/default.rb` は priority 15 の profile を生成しますが、
  変更前は旧 `50-fzf-tab.sh` を削除しませんでした。
- `cookbooks/sheldon/default.rb` は priority 20 で deferred plugins を読み込みます。
  実機の profile directory と bundle の両方に旧 50 と現行 15 が存在しました。
- fzf-tab `24105b15714bfec37989ed5c5b6e60f572253019` の
  `fzf-tab.zsh:336` は `zle -N fzf-tab-complete` で widget を再登録します。
  再読み込み後は autosuggestions wrapper ではなく元の widget になります。
- autosuggestions `85919cd1ffa7d2d5412f6d3fe437ebdbeeec4fc5` の
  `zsh-autosuggestions.zsh:303` の wrapper が `POSTDISPLAY` を消去します。
  この処理を通らないことと、補完後の残存値が一致します。
- `roles/foundation/templates/profile` は変更前、残存ファイルの mtime だけで
  bundle を更新していました。古い profile の削除だけではキャッシュが残ります。

修正は旧 50 の削除と、profile directory の変更時にも bundle を更新する処理です。

## 検証

`python3 bin/test-shell-completion --plugins --output <新規の私有ディレクトリ>`
で cookbook の削除指定、削除後の zsh bundle 再生成、PTY 比較を実行します。
既存 profile や端末には入力せず、インストール済み plugins を読み取ります。

- 幅 80 / `xterm-256color` / Nerd Font 文字を含む2行 prompt
- 幅 40 / `screen-256color` / 日本語・曖昧幅文字・右 prompt
- 日本語ディレクトリ名の補完

各組で旧設定の残存と修正後の解消を確認しました。
変更前の cookbook を使うと削除指定のテストが失敗し、変更前の profile template
を使うと削除後の bundle テストが失敗します。

Herdr の私有 named session でも補完前・補完後・再描画後のセルと BUFFER を比較し、
旧設定のみ残存することを確認しました。TUI の出力も採取しました。
この再現では GPUI paint、CSI/OSC のタイミング、文字幅の差は発生に不要です。

観測キーは補完が終了してから送ります。Tab と snapshot キーを続けて送ると、
autosuggestions の `PENDING` 分岐が候補を復元し、測定自体が結果を変えます。
